部件②

skill · 这个场景的学术逻辑

场景的方法(步骤 / 判断标准 / 硬约束 / 停点)固化成一个 skill。这里只引用它——生成一条调用指令,不在网页里展开逻辑。

为什么把方法搬进 skill? 埋在网页字符串里的逻辑不直观、也难改。写成 SKILL.md 后:一处维护、能被多个场景复用、还能单独打磨。 放进项目或全局 skills/ 目录,Claude Code 会按 skill 描述自动匹配,也可以直接 /选题探索 调用。 还没有 skill?先用教程 D 的 SKILL 模板把方法写出来,再回来引用它。
部件③

prompt 生成和复制

落盘写相对路径 产出/文件名——你在 Claude Code 里已经在项目文件夹里了,不用再给绝对路径,所以这版去掉了状态区。

prompt = context + 调用你的 skill + 落盘。部件①收值 → 拼成 context;部件②给出 skill 调用指令;这里补上落盘 → 送到剪贴板。HTML 自己不跑 AI,它只让"和 AI 合作的第一步"不再从空白对话框开始。

点「生成预览」查看完整 prompt。三块会分开显示:深色 = 机械件(context / 落盘),暖色 = 调用你的 skill。
