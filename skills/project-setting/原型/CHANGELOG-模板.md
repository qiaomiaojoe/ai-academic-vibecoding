# 【工作台名】· 版本日志

工作文件只有一个：`../【工作台名】.html`（永远是最新版）。
`工作台版本/` 里是冻结快照，只读，不要在快照上改东西。

## 版本号规则

| 号段 | 含义 |
|------|------|
| **0.x** | 还在自己折腾，没拿它正经干活 |
| **1.0** | 第一个真正拿来干活 / 给别人用的版本 |
| **1.x** | 之后的迭代 |

版本号只写在一处：工作台 HTML 里 `<script>` 开头的 `const WB_VERSION`。
导航、页脚、浏览器标签页的版本号都由它自动填。

## 每次改完要做的两件事

1. `WB_VERSION` 加 0.1
2. 在下面「版本记录」顶部加一条：版本号 / 日期 / 改了什么 / 为什么

要留快照就在 `工作台/` 下跑：

    ./快照.sh

同一个版本号重复跑会拒绝覆盖，逼你先加 0.1。

> **为什么值得记这个日志？**
> 三个月后你会想不起来"当初为什么把那个下拉改成勾选"。
> 一行字的成本，换的是以后不用重新想一遍。
