# 材料读取：逐份分类

对 `raw/` 里每个文件（含子文件夹，跳过隐藏文件）按扩展名和实测结果分类。

| 类型 | 判定 | 动作 | 文本来源 |
|---|---|---|---|
| `.md` `.txt` `.markdown` | 扩展名 | 直接读 | 原文件 |
| `.pdf` 有文字层 | `pdftotext -layout <文件> -` 输出的非空白字符 ≥ 页数 × 100 | 抽取到 `.kb-cache/<相对路径>.txt` | 缓存文件 |
| `.pdf` 无文字层 | 上面的输出不够（通常是扫描件） | **跳过**，原因：「扫描件，无文字层」 | —— |
| `.pdf` 但没有 pdftotext | 命令不存在 | 用当前环境能读 PDF 的方式读；读出的文字同样按上条阈值判定 | 缓存文件 |
| `.docx` `.doc` `.rtf` | 扩展名 | mac：`textutil -convert txt -output .kb-cache/<相对路径>.txt <文件>`；其他系统用可用的转换方式 | 缓存文件 |
| 上面转换失败 | 命令报错或输出为空 | **跳过**，原因写报错首行 | —— |
| `.html` | 扩展名 | 去掉标签后读正文 | 原文件 |
| 图片、音频、视频、`.xlsx` `.pptx` `.zip` 等 | 其他一切 | **跳过**，原因：「暂不支持的格式：<扩展名>」 | —— |

## 规矩

- **抽取文本只进 `.kb-cache/`**，绝不写进 `raw/`。
- 缓存已存在且原文件修改时间没变 → 直接用缓存，不重复抽取。
- 页数查不到时（如 `pdfinfo` 不可用），按「抽出文本 ≥ 500 个非空白字符」判定有文字层。
- 概念页 frontmatter 的 `raw:` 字段**永远指向 `raw/` 里的原文件**，不指向缓存。
- 一份材料超过约 15000 字：按标题/章节分段；没有标题就按约 15000 字切，逐段处理，同一份材料只在 log 里记一条。
